## HBK Maths Quest — Grades 1–10 (NCERT)

A playful, gradient-heavy maths practice app inspired by the HBK English Quest layout. Each grade is a "world" with NCERT chapters as levels; each chapter has 25 mixed-format questions generated on demand by Lovable AI. No login — progress is stored locally in the browser.

### Pages / Routes

- `/` — Home (hero banner, stat cards, Problem of the Day, mode cards, "Choose your world" grid of 10 grade cards)
- `/grade/$gradeId` — Chapter list for that grade (NCERT chapter titles as level cards, progress per chapter)
- `/grade/$gradeId/chapter/$chapterId` — Quiz screen (25 questions, one at a time, instant feedback, progress bar, XP at the end)
- `/daily` — Daily Challenge (5 mixed questions, 2× XP)
- `/tutor` — "Ask HBK Mathy" learning mode (free-form AI tutor chat)
- `/custom` — Build-your-own test (pick grade, chapters, count, difficulty)
- `/progress` — My Progress (stars, XP, streak, per-grade breakdown)

### Visual direction (matches the reference)

- Vivid gradient hero (purple → pink → blue), white rounded cards, soft pastel background
- 10 grade cards in a responsive grid, each its own solid color + cute mascot illustration and a themed "world" name (e.g. *Counting Cubs*, *Fraction Falls*, *Geometry Grove*, *Algebra Atoll*, *Trigon Tundra* …). Mascots generated as transparent PNGs.
- Stat tiles: **Problem Stars**, **Concept Stars**, **XP**, **Day Streak**
- "Problem of the Day" card replaces "Word of the day"
- Mode cards: *Ask HBK Mathy* (learning) and *Custom Test* (build-your-own)
- Friendly mascot ("HBK Mathy" dragon) in the hero
- Design tokens defined in `src/styles.css` using `oklch`; no hardcoded colors in components

### Question system

- **25 questions per chapter**, generated by **Lovable AI** (`google/gemini-3-flash-preview`) via a TanStack Start server function using structured tool-calling for reliable JSON
- **Mixed formats per chapter**: MCQ (4 options), fill-in-the-blank, true/false, and short-answer (numeric). The model returns a typed array; the UI renders the right widget per type.
- Questions are cached in `localStorage` per `(grade, chapter)` so the same set is reused on retake until the user taps "New set"
- Each question has: `type`, `prompt`, `options?`, `answer`, `explanation`, `difficulty`
- Server-side prompt is grade- and chapter-aware (uses the NCERT chapter title) and instructs the model to follow NCERT scope

### NCERT chapter data

Static map in `src/data/ncert-maths.ts`: grade → array of chapter titles (latest NCERT syllabus for grades 1–10). Used to drive the chapter list, the quiz prompt, and SEO metadata.

### Progress & gamification (anonymous, localStorage)

- Per-chapter: completed count, best score, stars (1–3 based on % correct)
- Aggregates: total stars, XP, daily streak (tracked by last-played date)
- Daily Challenge gives 2× XP and increments streak
- Small confetti + sound on correct streaks (subtle, optional)

### Tech notes

- TanStack Start with file-based routes under `src/routes/`
- `src/lib/quiz.functions.ts` — `generateChapterQuiz`, `generateDailyChallenge`, `gradeShortAnswer` server functions calling Lovable AI gateway with tool-calling
- `src/routes/api/tutor.ts` — SSE streaming endpoint for the tutor chat
- `src/hooks/useProgress.ts` — localStorage-backed progress store
- `src/components/quiz/` — `MCQQuestion`, `FillBlankQuestion`, `TrueFalseQuestion`, `ShortAnswerQuestion`, `QuizRunner`, `ResultScreen`
- `src/components/home/` — `HeroBanner`, `StatTiles`, `ProblemOfTheDay`, `ModeCards`, `GradeCard`
- Mascots generated with `imagegen` (transparent PNGs) — one per grade + one main "HBK Mathy"
- Per-route `head()` with unique titles/descriptions; `og:image` only on leaf routes
- Requires enabling **Lovable Cloud** (for the Lovable AI gateway / `LOVABLE_API_KEY`); no database, no auth

### Out of scope (call out so it's explicit)

- No user accounts / cross-device sync (progress is per-browser)
- Not a literal clone of the source site — same look & feel, Maths content, original mascots and color palette per grade
- No teacher dashboard, no leaderboards
